# damo_link

32 位单片机烧录工具（Windows 可执行版）。

基于 [probe-rs](https://probe.rs/) 的图形化烧录工具，支持探针枚举、芯片三级级联选择、固件烧录 / 校验 / 擦除 / 复位。

## 使用方法

1. 下载本目录全部文件
2. 运行 `damo_link.exe`
3. 点「刷新探针」→ 选择芯片 → 选择固件 → 烧录

> 烧录后端 `probe-rs\probe-rs.exe` 需与 `damo_link.exe` 保持同一目录结构。

## 功能特性

- 三套背景主题（深色 / 米白色 / 白色），右上角齿轮切换
- 配置自动保存（芯片、主题、协议等），下次打开自动恢复
- 探针自动枚举（DAPLink / ST-Link / J-Link 等）
- 芯片三级级联选择（厂商 → 系列 → 型号）
- 烧录 / 校验 / 擦除 / 复位，烧录成功后自动复位运行
- 实时日志流式显示

## 配置

首次运行后会在同目录生成 `damo_link_config.json` 保存你的设置（该文件不随仓库分发）。
